# 🚗 Car Price Predictor

A Machine Learning web application that predicts the resale price of used cars using a Random Forest Regressor.

## Features

- Predicts used car resale prices
- User-friendly web interface
- Trained using Scikit-Learn
- Flask backend
- Random Forest Regression model

## Tech Stack

- Python
- Flask
- Scikit-Learn
- Pandas
- HTML
- CSS
- JavaScript

## Project Structure

```
Car-Price-Predictor/
│── app.py
│── car_price_random_forest.pkl
│── requirements.txt
│── templates/
│── static/
```

## Installation

```bash
git clone https://github.com/DhawalDeshmukh72/Car-Price-Predictor.git

cd Car-Price-Predictor

pip install -r requirements.txt

python app.py
```

Visit:

```
http://127.0.0.1:5000
```
